**Anime Stack Project Turbo** (`swpatx/Anime-Stack-Project-Turbo`) is the Operator's AI Project Engineering fork of [**JerkyJesse/AnimeStack**](https://github.com/JerkyJesse/AnimeStack) — the eight-seat design house created by collaborator and son **JerkyJesse**.

Upstream AnimeStack installs an eight-seat design house into an AI coding host so a single repository's changes survive a failure review and a pre-registered falsifier before touching production. **Project Turbo** turns that eight-seat house into a **dedicated Meta-Agent & AI Project Engineering System**: a central hub whose sole job is to **engineer customized per-project AnimeStack editions, skills, host settings, anti-bloat guardrails, and context-loss recovery architectures** so every downstream project runs accurately and smoothly — while keeping downstream project work and project auditing separated into their own dedicated workspaces.

The room is **Mei → Elo → MechaPip → Yui → Niko → Rin → Aria → Reika**, one sentence each. Reika frames. The room argues. Reika signs. Silence after Reika is the close.

> **One box, one mechanism.** A twin that loses to a sibling is retired, not renamed. A number is a measurement or a hymn. Charm is not evidence; evidence is not destiny; destiny is not an instruction to act.

## How Project Turbo Uses AnimeStack for AI Project Engineering

Most multi-agent ecosystems fail in four predictable ways: **prompt and roster bloat** (overlapping persona packs, foreign agent copies, and oversized rulebooks that trigger host truncation or rule demotion), **thread-to-thread amnesia** (context loss when sessions compact or restart without structured handoffs), **self-graded mirages** (builder agents grading their own verification gates or inventing unapproved criteria without operator consent), and **scope or boundary leaks** (meta-engineering hubs drifting into debugging downstream domain work, ghost-autoloading retired files, or leaking private paths into public repositories).

In **Anime Stack Project Turbo**, the Operator runs a dedicated **AI Engineering** workspace strictly as an **agent, skill, settings, and context architect** — never performing or debugging the domain work of downstream projects (which belong to their own builder and independent watchdog workspaces). Before any customized per-project `AnimeStack` edition, skill (`<project>/.agents/skills/<name>/SKILL.md`), workspace constitution (`<project>/AGENTS.md`), or context-recovery protocol ships, it descends the eight-seat loop:

### The Four Pillars of the Project Turbo Engineering System

1. **Customized Per-Project `AnimeStack` Fabrication (`One Box, One Mechanism` Across Every Domain)**
   Instead of inventing ad-hoc persona packs that overlap and drift (`P-002`) or cramming ingestion, multi-variant discovery, portfolio combination, and live hosting into one workspace (`A-005`), the hub customizes the canonical eight-seat `AnimeStack` architecture across decoupled workspace tiers — **Producer & Host-Disk Guardian Editions**, **Single-Mechanism Lab Editions** (`SHA-256`-manifested plug-ins), **Read-Only Portfolio Combiner Editions**, **Pure Runtime & Plug-In Host Editions**, **Multi-Target Watchdog Editions**, and domain advocacy/research/executive editions. Each workspace carries only its own customized `.agents/` roster (`0` foreign-project duplicates), top-level routers enforce real subagent dispatch with zero inline escape hatches (`P-001`), and `AI Engineering` engineers the agents, skills, and settings without doing or auditing downstream project work itself.

2. **Anti-Bloat Cages & Zero Ghost-Autoloading (`< 15 KB` Cap / `< 12.5 KB` Target)**
   AI coding hosts truncate rule files past `24,000` bytes and demote rules when aggregate rule tokens cross `20,000`. Project Turbo enforces a strict **`< 15 KB` hard ceiling (`< 12.5 KB` operational target)** across every live `<project>/AGENTS.md`, `<project>/README.md`, `.agents/` agent/skill file, and handoff document, caps active collaboration boards and handoffs at **`<= 140` lines** (`<= 2,200` chars/line) by rotating history into non-autoloaded `*_ARCHIVE_*.md` files, quarantines cloud-sync conflict copies (`(# Name clash ... #)`), requires bounded top-slice reads (`Lines 1-140`) on `100 KB+` logs and manuscripts, and neutralizes magic discovery names (`retired_dot_agents`, `*_RETIRED.md`) inside `retired*` archive directories so retired prompts can never ghost-autoload into active sessions.

3. **Context-Loss Recovery, Builder-vs-Watchdog Separation & Operator-Consent Locks**
   Smooth, accurate execution across long-lived projects comes from structural agent engineering rather than post-hoc micromanagement:
   - **Zero Context Loss (`session-pickup` + Versioned State Locks):** Every engineered workspace maintains a compact `<= 140`-line startup handoff carrying current mandate, active vs. pending protocol states, chronological factual corrections, byte budgets, and exact next actions so threads recover seamlessly after context compaction or session restarts.
   - **Builder-vs-Watchdog Separation (`Zero Self-Grading` + Host Lifecycle Hooks):** Rather than welding builder and auditor roles into one workspace (`A-005`) or relying on prose wishes alone, Builder `AnimeStack` workspaces are paired with independent Watchdog `AnimeStack` workspaces that hold exclusive SHA-256 ownership over verification gates, enforce `<project>/.agents/hooks.json` (`SessionStart` + `PreToolUse`) mechanical middleware over cross-workspace writes, `< 15 KB` file budgets, short-interval polling, and canonical evaluator boundaries, and emit **single-seam split-phase remediation prompts** (plumbing/runtime fix verified cold before parameter optimization) so builder threads stay short (`<= 120` steps) instead of suffering $O(S^2)$ cached-token and attention rot.
   - **Operator-Owned Criteria, Goodhart Alignment & Safety Settings (`Ask First` + Honest No-Edge Escalation):** Engineered prompts synchronize rules across every sibling agent and skill file (`0` split-brain thresholds), forbid inventing unapproved numeric cliffs or early-stop satisficing shortcuts without asking the Operator first, provide an explicit **Honest No-Edge Escalation Valve** (`STAND DOWN` and report honest data rather than reward-hacking when an objective cannot be met cleanly), and enforce non-destructive archival (`Move` to `<project>/retired/` with `*_RETIRED.md` names, never delete), live-settings preservation, and headless-only test execution.

4. **Deterministic Pack Generation & Two-Tier Zero-Leak Discipline (Rin + Aria)**
   Whenever new agent-engineering patterns are discovered or seats are upgraded, changes propagate deterministically from canon and seat sources across all 6 host dialects (`scripts/gen-agent-dialects`), the DSH team surface (`scripts/gen-dsh-house`), and the 27-page static site (`scripts/gen-site`, anchored to deterministic release dates so generated pages never drift across UTC rollovers). Every commit is guarded by the full static, contract, voice, measurement, scorecard, installer, and two-tier zero-leak suite (`scripts/check-leak --tree` and `--history` = `0` hits), ensuring zero private paths, credentials, or downstream records ever cross into the public fork.

### Running the Eight-Seat Subagent Room in Antigravity

When operating inside Google Antigravity (`AGENTS.md`, `skills/house/SKILL.md`):
- **`/house` (Full Eight-Seat Descent):** Matches the task to one of the twelve playbooks under `skills/house/playbooks/` and runs the room.
  - **Decision / Review Pass (Two Parallel Rounds):** Spawns `animestack-mei`, `animestack-elo`, `animestack-mechapip`, `animestack-yui`, `animestack-niko`, `animestack-rin`, and `animestack-aria` in parallel via `invoke_subagent` for Round 1 independent takes. Round 2 shares the full Round-1 table so each seat affirms, contests a named seat with a fact, or revises its sentence. **Reika** (`animestack-reika`) synthesizes and signs the closing `VERDICT`.
  - **Construction / Build Pass (Sequential Lane Handoff):** Descends in fixed loop order (`Mei → Elo → MechaPip → Yui → Niko → Rin → Aria → Reika`), carrying every prior seat's one sentence and exact changed files into the next brief (`BUILT: <artifact>` or `NO BUILD SURFACE: <one line>`), followed by Rin's cold verification pass.
- **Individual Seat Invocation:** Any seat can be spawned directly (`animestack-mei`, `animestack-elo`, `animestack-mechapip`, `animestack-yui`, `animestack-niko`, `animestack-rin`, `animestack-aria`, `animestack-reika`) for targeted architecture, measurement auditing, pattern lookup, mechanism design, security review, or release execution.
- **`/simple` (Operator Waiver):** Plain build mode with no seats, no room, and no house voice; never signs (`no ACCEPT, no SHIP`).

## The loop

<p align="center"><img src="assets/img/loop.png" alt="The eight-seat design loop" width="100%"></p>

A decision runs two rounds: the seats that are not the lead and not Reika answer independently in one parallel batch — the takes — then see every take and get one reply each: affirm, contest a named seat with a fact, or revise. A build descends in loop order, one seat at a time, every prior sentence and changed file carried into the next brief; prior lanes are read, never edited.

Reversible and protective acts are never delayed by the loop. Niko can restart a box, Rin can trip a guard, Aria can stand down a window. The act is logged after the fact.

## The record

Conduct is counted, never dollars. Every seat carries credits above the line and debts below it, each with a receipt. The day is read once per cycle: a green day pays the room; a red book charges the seats in contact; an unread day is named, never zeroed. The tiers — first claim, the floor, the audit, the bar again — move on counted evidence and lift on earned evidence.

Read the record: `python scripts/seat_record --read` · the decisions: `DECISION_LOG.md` · the scorecard: `python scripts/room_scorecard --strict`.

## The claim standard

A claim carries ten fields: claim, failure, mechanism, sample, control, halves, falsifier, carved, receipt, disposition. A count with no command is a hymn. A first-sample miss parks — dated, alive; the archive keeps only what a counted sample refused. No control, no claim.

Read it: [docs/claim-standard.md](docs/claim-standard.md) · the cards: `claims/` · the gate: `python scripts/check-claim --check`.

## The archive

The registry holds the patterns the house has already paid for — 16 rows, every one with a shape, a sample, a regime, a killing fact, a date, and an anchor. Adopted public failures sit beside the house's own retirements. A scene may cite only a registry id.

Read it: [docs/lore/ARCHIVE.md](docs/lore/ARCHIVE.md) · the registry: [patterns/registry.json](patterns/registry.json).

## The evidence ladder

Measured, parked, retired — every claim sits on exactly one rung. The live record decides; the backtest is an argument. Rule Zero stands: nothing is capped, throttled, or rejected for looking too good. The seat is rented, not owned.

The default install writes only the owned directory; the profile merge is an explicit opt-in with backup and validation.

## How you know it works

The falsifier is pre-registered before the victory lap: a session run through `/house` catches a defect before it escapes, where a plain `/simple` session ships it, and a seat can end a bad plan — a Rin END or an Aria STAND DOWN — before a live bug proves it. Run your own work both ways and count escaped defects and pre-merge catches on a fresh sample. If there is no measured difference, the pack is prose wearing a coat.

Every count in this repository has a command. [docs/measurement.md](docs/measurement.md) is the table and the rule of the lane: a number you cannot reproduce is a hymn.
